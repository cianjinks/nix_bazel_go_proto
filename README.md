# Go + gRPC + Bazel + Nix

An example project for developing Go + gRPC using Bazel on NixOS. Uses Bazel 7 + Bzlmod.

Relevant links:

 - VSCode integration: [editors.md](https://github.com/bazel-contrib/rules_go/blob/master/docs/editors.md)
 - Why I didn't use `rules_nixpkgs`: [bazelcon](https://bazelcon2024.sched.com/event/1h6SL/nix-and-bazel-the-odd-couple-of-build-tools-jesse-schalken-canva?utm_source=chatgpt.com)
 - Avoiding protoc recompilation: [toolchains_protoc](https://github.com/aspect-build/toolchains_protoc)
